# AGENTS.md

This repository packages Penpot as a JSONbored Unraid-first AIO app.

## Intent

- Keep the default Unraid install close to one-click.
- Bundle the services required for first boot in one container.
- Expose the full discovered Penpot configuration surface in Advanced View.
- Keep shared CI, release, registry, and catalog policy in `aio-fleet`.

## Source Of Truth

- `penpot-aio.xml` is generated by `scripts/generate_penpot_template.py`.
- `docs/upstream/penpot-config-inventory.json` is generated by `scripts/refresh_upstream_inventory.py`.
- `.aio-fleet.yml` is exported from `aio-fleet/fleet.yml`.
- `awesome-unraid` receives catalog XML/icon assets only after source validation.

## Runtime Contract

- Persist generated secrets in `/appdata/config/generated.env`.
- Treat explicit Unraid template values as overrides.
- Keep `/appdata/config/extra.env` as the final escape hatch, not the normal config path.
- Keep internal services bound to localhost unless a template option deliberately exposes a host port.
- Do not remove bundled PostgreSQL, Redis-compatible cache, Mailpit, exporter, or MCP without updating the template, tests, and docs together.

## Validation

Use the smallest relevant ladder:

```sh
python3 scripts/generate_penpot_template.py --check
pytest tests/template
pytest tests/integration -m integration
```

From `aio-fleet`:

```sh
python -m aio_fleet validate-repo --repo penpot-aio --repo-path ../penpot-aio
python -m aio_fleet cleanup-repo --repo penpot-aio --repo-path ../penpot-aio --verify
python -m aio_fleet control-check --repo penpot-aio --repo-path ../penpot-aio --event pull_request --dry-run
```
